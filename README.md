A one-image summary of the world's news of Monday 23 November 2026,
drawn as a newspaper front page: the Iran war widening into the Strait
of Hormuz, Ukraine sinking a Russian warship off Libya, COP31 collapsing,
markets rebounding, the Democrats' biggest House win since 1992, and the
alleged Russian plot in Denmark.

`main.py` draws `entry.png` (1024x1024) with `render_frontpage.py`
(Pillow, vendored DejaVu fonts in `assets/`), or copies the shipped
`entry.png` if drawing is unavailable. Both runs write the same bytes.

Built for the [make.fun bounty](https://make.fun/bounty/news-image-20261123).
